# Claude Code コマンド（スラッシュコマンド）一覧

Claude Code（このセッション）で使用できるスラッシュコマンド（スキル）の一覧です。後から見直せるように整理しています。

作成日: 2026-09-03

## 開発・コード品質系

| コマンド | 説明 |
|---|---|
| `/code-review` | 現在の差分やPR番号・ブランチを対象に、正確性のバグや再利用・簡潔化・効率化の観点でレビューする。effortレベル（low/medium/high/max/ultra）を指定可能。`--comment`でPRにインラインコメント投稿、`--fix`で指摘を自動修正。`ultra`はクラウド上でのマルチエージェントによる深いレビュー。 |
| `/ultrareview` | `/code-review ultra` の非推奨エイリアス（同じ機能）。 |
| `/simplify` | 変更されたコードを再利用性・簡潔さ・効率性の観点でレビューし、その場で修正を適用する。バグ探しは行わない（品質改善専用）。 |
| `/security-review` | 現在のブランチの保留中の変更に対してセキュリティレビューを実施する。 |

## セットアップ・設定系

| コマンド | 説明 |
|---|---|
| `/init` | 新規にCLAUDE.md（コードベースの説明ファイル）を初期化・作成する。 |
| `update-config` (設定変更全般) | `settings.json`の設定（フック、権限許可、環境変数など）を構成する。「〜のたびに」「〜する前に」等の自動化はフック設定が必要。 |
| `keybindings-help` | キーボードショートカットのカスタマイズ、キーバインドの変更を行う。 |
| `fewer-permission-prompts` | 過去の操作履歴から許可プロンプトを減らすための許可リストを`.claude/settings.json`に自動追加する。 |

## 実行・確認系

| コマンド | 説明 |
|---|---|
| `run` | プロジェクトのアプリを起動・実行し、変更が実際に動作することを確認する（サーバー、CLI、ブラウザアプリ等に対応）。 |

## デザイン・ビジュアル系

| コマンド | 説明 |
|---|---|
| `design` | デザインキャンバス（複数アートボードのビジュアルデザイン）をArtifactとして作成する。UIモックアップ、LP、ポスター、チラシなどに利用。 |
| `dataviz` | グラフ・チャート・ダッシュボードなどのデータ可視化を作成する際に使用するデザインガイド。 |
| `artifact-design` | Artifact作成前に読み込むべきデザインガイダンス。 |
| `artifact-diagramming` | Artifact内で図解（ダイアグラム）を描く際のノウハウ。 |
| `artifact-capabilities` | Artifactに持たせられるランタイム機能（データ保存、共有状態など）についてのガイド。 |

## 自動化・スケジューリング系

| コマンド | 説明 |
|---|---|
| `/loop` | プロンプトやスラッシュコマンドを一定間隔で繰り返し実行する。間隔省略時はモデルが自律的にペースを決定する。 |
| `schedule` | cronスケジュールで動くクラウドエージェント（ルーティン）の作成・更新・一覧表示・実行を行う。単発の予約実行にも対応。 |

## リファレンス系

| コマンド | 説明 |
|---|---|
| `claude-api` | Claude API / Anthropic SDKに関するリファレンス（モデルID、料金、パラメータ、ストリーミング、ツール利用、MCP等）。 |
| `claude-code-guide` (エージェント) | Claude Code本体、Claude Agent SDK、Claude API、Claude Tag等についての質問に答える専門エージェント。 |

---

### 補足
- コマンドは `/コマンド名` の形式で呼び出せます（例: `/code-review`, `/loop`）。
- 一部はスラッシュコマンドではなく「スキル」として内部的に呼び出されるもの（`design`、`dataviz`など）で、該当するタスク発生時に自動的に案内されます。
- 利用可能なコマンドはプロジェクトやセッションの設定によって変動する場合があります。
