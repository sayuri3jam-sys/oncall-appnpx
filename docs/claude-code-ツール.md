# Claude Code ツール一覧

Claude Code（このセッション）が利用できるツールの一覧と説明です。後から見直せるように整理しています。

作成日: 2026-09-03

## ファイル操作系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| Read | ローカルのファイルを読み込む（画像・PDF・Jupyter Notebookにも対応） | コードの内容確認、画像やPDFの中身確認 |
| Write | ファイルを新規作成、または全体を上書き保存する | 新規ファイル作成、既存ファイルの全面書き換え |
| Edit | ファイル内の文字列を部分的に置換する | 既存コードの部分修正（差分のみ送信できて効率的） |
| NotebookEdit | Jupyter Notebook（.ipynb）のセルを編集する | ノートブックのコード/出力の編集 |
| Glob | ファイル名のパターン検索（例: `**/*.ts`） | ファイルをパスパターンで探す |
| Grep | ripgrepベースの高速な内容検索（正規表現対応） | コード内の文字列・関数名などを検索 |

## 実行系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| Bash | Git Bash（POSIXシェル）でコマンドを実行 | git操作、npm/テスト実行、シェルスクリプト |
| PowerShell | Windows PowerShellでコマンドを実行 | Windows固有の操作、レジストリ、.NET系タスク |

## エージェント・調査系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| Agent | サブエージェント（Explore、general-purpose等）を起動し、複雑な複数ステップのタスクを委任する | 大規模なコードベース調査、独立した並行タスク |
| ListAgents | 起動中のサブエージェントやチームメイトなど、メッセージ送信可能なエージェント一覧を表示 | 既存エージェントへの継続的なメッセージ送信 |
| ToolSearch | 遅延ロードされているツールのスキーマを検索・取得する | まだ読み込まれていないツールを呼び出す前の準備 |
| Skill | プロジェクトやユーザーが用意した「スキル」（定型ワークフロー）を呼び出す | `/code-review`、`/loop` などのスラッシュコマンド実行 |

## Web系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| WebFetch | 指定したURLの内容を取得する | ドキュメントや外部情報の参照（ユーザー提供URLのみ） |
| WebSearch | Web検索を行う | 最新情報や外部知識の調査 |

## コミュニケーション・成果物系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| Artifact | HTMLページを「Artifact」としてWebに公開する（プレビュー・ダッシュボード等） | ビジュアルなレポート、UIモックアップ、ミニアプリの公開 |
| SendUserFile | 生成したファイル（レポート、スクリーンショット等）をユーザーの別デバイスに送付 | 成果物をチャット外で確認できるように渡す |
| SendMessage | 他のエージェント／セッションにメッセージを送信 | サブエージェントやチームメイトとの連携 |
| PushNotification | プッシュ通知を送信 | 長時間タスク完了などの通知 |
| AskUserQuestion | ユーザーにしか判断できない事項について選択式の質問をする | 曖昧な仕様確認、方針の選択 |

## タスク管理・自動化系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| ScheduleWakeup | `/loop`の動的モードで次回起動タイミングを予約する | 一定間隔での自律的なタスク再開 |
| CronCreate / CronList / CronDelete | 定期実行（cronジョブ）の作成・一覧・削除 | クラウド上でのスケジュール実行タスク管理 |
| Monitor | バックグラウンドプロセスのイベントをストリーム監視 | 長時間実行コマンドの進捗確認 |
| TaskOutput / TaskStop | バックグラウンドタスクの出力取得・停止 | 非同期実行中タスクの管理 |
| RemoteTrigger | リモート環境でのトリガー実行 | クラウド／リモートエージェントの起動 |

## モード切り替え系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| EnterPlanMode / ExitPlanMode | 実装前に計画を立てるプランモードの開始・終了（承認待ち） | 大きな変更の前に方針をユーザーに確認 |
| EnterWorktree / ExitWorktree | Gitの作業ツリー（worktree）を切り替える | 独立した作業ブランチでの並行作業 |

## レビュー系

| ツール名 | 説明 | 主な用途 |
|---|---|---|
| ReportFindings | コードレビューの結果を構造化して報告する | `/code-review`スキル実行時の指摘事項の出力 |
| DesignSync | デザイン関連の同期処理 | デザインツールとの連携 |

---

### 補足
- 一部のツール（Monitor、SendMessage、WebFetch など）は「遅延ツール」で、`ToolSearch` を使ってスキーマを取得してから呼び出す仕組みになっています。
- ツール構成はセッションや設定（MCPサーバーの接続状況など）によって変動する場合があります。
